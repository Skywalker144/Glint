# Glint 产品方案

Glint 是基于 **Tauri 2** 的轻量桌面翻译工具，交互参考 [Bob](https://github.com/ripperhe/bob)。首版仅支持 macOS。本文定义产品目标，实现入口与验收状态见 [开发文档](development.md)。

## 1. 首版范围

| 功能 | 行为 |
| --- | --- |
| 划词翻译 | 选中文字后按全局快捷键，在选区附近打开结果窗；普通选中不弹窗 |
| 输入翻译 | 快捷键或菜单栏左键打开输入窗；Enter 查询，Shift+Enter 换行，输入法组词时不提交 |
| 截图翻译 | 快捷键框选屏幕，OCR 后进入同一结果窗；原文可修正、重新翻译 |
| 菜单栏 | 常驻图标，右键菜单提供「设置」「退出」；关闭结果窗不退出应用 |
| 生词本 | 从结果收藏单词或短语，在结果窗工具栏打开生词本 |
| 设置 | 配置三个全局快捷键与 AI 服务，默认预设 DeepSeek |

三种入口共用同一结果窗与查询逻辑。全文翻译、AI 聊天、复习计划和云同步不在首版范围。

## 2. 翻译方向

- 默认自动：中文 → 英文；其他语言 → 中文。混合文本按主体语言判断，无法确定时提示选择源语言。
- 语言栏为「源语言 ⇄ 目标语言」，自动时显示检测结果，如「自动（英语）⇄ 中文」。两侧可选语言，支持恢复自动。
- 手动指定优先，另一侧沿用已解析语言；编辑、重试保持方向，从三个入口重新唤起查询时恢复自动。
- 点击箭头：将自动状态解析为具体语言后交换，进入手动状态；有完整译文时将其填入原文区重新翻译，否则保留原文供编辑。
- 词典卡片没有唯一译文，交换时保留查询文本，待用户修改后查询。

## 3. 结果窗与词典卡片

视觉参考用户截图：浅色浮窗、浅灰圆角原文与结果卡片、紧凑图标工具栏、蓝色词语链接和可折叠栏目，首屏优先显示答案。

- 顶部：固定窗口、收藏、生词本、设置与收起；可编辑原文卡片底部提供系统朗读、复制和语言识别提示，其下为语言栏和「词典 / 翻译」切换。
- **词典模式**：词头 → 原查询词及词形关系 → 音标与发音 → 按词性分组的释义；下方按需展开例句、词组、近反义词与辨析。缺失栏目隐藏，不补造音标或标签；系统朗读与词典录音明确区分。
- **翻译模式**：默认由 DeepSeek 翻译，原文与流式译文分卡片展示，译文卡片支持折叠、系统朗读和复制，并保留停止和重试。
- 单词、已收录的固定短语默认查词，句段默认翻译，允许手动切换；不能仅凭有无空格判断是否为单词。
- Esc 或关闭按钮收起结果窗，回到原应用；固定时失焦不收起。编辑原文后标记结果待更新，连续查询只展示最新请求的结果。

## 4. 词典实现与词形判断

**保留原查询词，关联词头，不丢掉独立词义。** 本地词库先做英汉；其他语言方向用相同卡片展示对应语言的「AI 释义」。

处理顺序：

1. 保留输入，查询完整词条、固定表达与词形关系；不用删词尾代替词形还原。
2. 确认是单纯变形且词头唯一时，展示原形并标注关系；不能把“命中词条”等同于“有独立义项”。
3. 独立义项优先保留，另列原形；有歧义时保留原词与候选供选择。用户提供上下文后，AI 才可辅助排序。

| 输入 | 预期展示 |
| --- | --- |
| `quantities` | 词头 `quantity`，注明「quantities 是 quantity 的复数」，保留原查询词 |
| `goods` | 优先展示「商品、货物」等独立含义，同时保留与 `good` 的关系 |
| `saw` | 同时保留「锯 / 锯切」和 `see` 的过去式；无上下文不替用户选定 |
| 固定短语 | 整体查询，不逐词还原后拼接 |

建议采用 **本地词典 + DeepSeek 补充**：

- 候选 [ECDICT](https://github.com/skywind3000/ECDICT) 提供释义、音标及 `exchange` / lemma 关系，转为只读 SQLite 查询。它不保证义项消歧，选型须验证上述样例；证据不足保留候选。
- 本地命中立即展示，离线可查；缺词、例句或辨析由 DeepSeek 补充，标明来源，不覆盖词库释义。
- AI 以 [JSON](https://api-docs.deepseek.com/guides/json_mode/) 返回词头、词形关系、分词性释义、例句与词组，校验后渲染；空响应或格式错误支持重试。

## 5. 生词本与设置

**生词本**：本地保存词头、原词、语言方向、释义及来源、上下文与时间，支持搜索、查看、删除和导入导出。按语言和已确认词条去重，新语境追加；歧义未消除不合并，`goods` 不归入 `good`。

**设置**：三个快捷键独立录制，冲突或注册失败保留旧绑定并提示。预设 DeepSeek，可填 API Key、选择模型、测试连接，也可配置兼容接口。密钥存入系统凭据存储；服务失败不影响本地词典和生词本。

## 6. 技术边界与验收

Tauri 2 承载界面，Rust 统一处理平台能力、查询与存储。菜单栏与快捷键使用官方 [System Tray](https://v2.tauri.app/learn/system-tray/) 和 [Global Shortcut](https://v2.tauri.app/plugin/global-shortcut/)；取词与截图/OCR 接入 macOS 能力。

先验证 Zotero、浏览器的取词与焦点恢复，以及词典数据对上表的覆盖。

验收覆盖三种入口、语言方向及交换、词典样例、收藏持久化、菜单栏设置与退出。取词失败不读旧剪贴板，OCR 可修正，权限不足有操作指引，服务失败保留原文和已有结果。
